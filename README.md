# Oil Express 프론트엔드 시제품

가정용 난방유를 배달하는 소규모 유류 판매자를 위한 업무용 웹 화면 시제품입니다. 모든 고객·주문 정보는 가짜 예시 데이터이며, 브라우저 화면 안에서만 변경됩니다.

## 실행 방법

Node.js 20 이상이 설치된 환경에서 다음 명령을 실행합니다.

```powershell
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(일반적으로 `http://127.0.0.1:5173`)를 브라우저에서 엽니다.

## 빌드

```powershell
npm run build
```

## 포함된 화면

- 판매자 대시보드
- 고객 관리 및 고객 등록·상세 보기
- 주문 관리 및 주문 등록·배송 상태 변경
- 배송·수금 관리
- 고객용 모바일 간편 주문 페이지

## 현재 범위

React, TypeScript, Vite, CSS만으로 제작한 시제품입니다. 서버, 데이터베이스, 실제 로그인, 문자 발송 및 외부 API 연결은 포함하지 않습니다.
